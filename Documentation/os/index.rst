=========
OS Design
=========

How NuttX is built, subsystem by subsystem.  The sections here follow the
source tree: what lives under ``sched/`` is described in
:doc:`scheduling/index`, what lives under ``fs/`` in the file system
section, and so on.  Each subsystem is described once, going from what it is
to how it works to the interfaces it offers.

For the POSIX interface an application sees, go to
:doc:`/reference/user/index` instead.
